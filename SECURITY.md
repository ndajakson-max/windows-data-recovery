# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

**Do not** open public issues for security vulnerabilities.

Instead, please email security concerns to the project maintainers with:

1. Description of the vulnerability
2. Steps to reproduce the issue
3. Potential impact
4. Suggested fix (if available)

We will respond within 48 hours to acknowledge receipt of your report.

## Security Considerations

This tool is designed for legitimate data recovery purposes only. Users should:

- Run the application with appropriate administrator privileges
- Only use this tool on systems they have authorization to recover data from
- Comply with all applicable laws and regulations
- Ensure proper backups exist before any recovery operations
- Review recovered files for security vulnerabilities or malware
